오늘 자습: 정올사이트에서 그리디알고리즘 문제 풀기
내 코드
```
import sys
input = sys.stdin.readline

N = int(input())
sb = [0] * N
for i in range(N):
    sb[i] = int(input())
sb.sort()

def solve(N):
    length = sum(sb)
    price = 0

    for i in range(N-1):
        price += length
        length -= sb[i]

    return price

print(solve(N))
```
